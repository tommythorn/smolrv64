# Arrays that MUST be inferred as RAM. Checked by tools/check-ram-inference.py after
# synthesis; a demotion to flops FAILS THE BUILD and names the array.
#
# Why a manifest and not just an attribute: `(* ram_style *)` asks the tool to try, and
# Vivado warns rather than errors when it cannot -- which is a silent regression on a design
# where nobody reads warnings. The attribute states intent at the declaration, this file
# enforces it. Both are wanted; only this one fails.
#
# Format:  <array-name> : why it must not become flops
# The name is the declared reg array, without the _reg suffix synthesis appends.
# `block[*].array xN` requires N generate instances of an array, every one a RAM.
#
# To REMOVE a line you must have decided the array is allowed to be flops -- say so in the
# commit message, with the reason. Do not delete a line to make a build pass.

# ---- the issue queue: the scheduler emits an INDEX, everything else is looked up ---------
# One payload and one source-tag array PER SCHEDULER since two-wide dispatch (item 10b,
# 2026-09-05): a pair dispatches to two different schedulers, so each array keeps one write.
plmem_i : issue payload, slot A's integer scheduler; read at the selected entry, one indexed read
plmem_i2: issue payload, slot B's integer scheduler (item 10d-ii)
plmem_l : issue payload, the in-order scheduler
plmem_f : issue payload, the FP scheduler
psmem_i : source tags; added 3b518832 after e_ps was demoted by the wakeup broadcast
psmem_i2: source tags, slot B's integer scheduler
psmem_l : source tags, the in-order scheduler
psmem_f : source tags, the FP scheduler
e_rob   : issue-queue ROB index, read only at [sel]

# ---- the physical register file: the largest array in the design ------------------------
mem_ie  : PRF integer shard; sharded by WRITER so each has ONE write port
mem_ld  : PRF load shard
mem_fe  : PRF FP shard
mem_ie2 : PRF second integer shard, written by the second ALU alone (item 10d-ii)

# ---- rename: free lists and maps, initialised by the bitstream and never reset ----------
# A `for` loop over every entry in the reset branch pinned all five into flops (~3,400 bits)
# purely to initialise them. Configuration does that for free. If one of these regresses,
# look for a reintroduced reset loop first.
# One generate block per shard, fl[shard], each with FLNB=next_pow2(IW) banks (one muxed write per
# bank: a cycle's frees land at tail, tail+1, tail+2). Two copies of each map since retire-two /
# dispatch-two (items 10b/10c): one write per bank per cycle is all a LUTRAM has.
fl[0].bank[*].mem x4 : free list, IE shard, 4 banks at IW=3 (circular FIFO, head read / tail write)
fl[1].bank[*].mem x4 : free list, LD shard, 4 banks at IW=3 (circular FIFO, head read / tail write)
fl[2].bank[*].mem x4 : free list, FE shard, 4 banks at IW=3 (circular FIFO, head read / tail write)
fl[3].bank[*].mem x4 : free list, IE2 shard, 4 banks at IW=3 (circular FIFO, head read / tail write)
# (fl[4], SH_IE3, has no allocator and no writer: synthesis may remove it)
rmap_a  : committed map, copy A; read at r_rs1/r_rs2/r_rs3 + c_rd, written at one index
rmap_b  : committed map, copy B (the second commit port's write; `rnewer` picks)
smap_a  : speculative map, copy A; flush clears `lv`, so no wholesale copy is ever needed
smap_b  : speculative map, copy B (rename port B's write; `newer` picks)

# ---- reorder buffer, frontend, predictor, MMU -------------------------------------------
rob     : ROB status
# NBANKS = next_pow2(IW) generate banks since Stage 3 inc 2 (was the two parity banks
# ent0/ent1, q_dat0/q_dat1). At the shipping IW=2 that is 2 banks each; at IW=3 add bank[2..3].mem
# and qbank[2..3].mem here in the same commit that flips the width.
bank[0].mem  : ROB entries, bank 0 (of NBANKS=next_pow2(IW))
bank[1].mem  : ROB entries, bank 1
qbank[0].mem : fetch queue data, bank 0 (of NBANKS=next_pow2(IW))
qbank[1].mem : fetch queue data, bank 1
ras     : return address stack
bank[0].btb : branch target buffer, halfword bank 0 of 8, 256 x 53 -- read as the fetch stream moves
bank[1].btb : branch target buffer, halfword bank 1 of 8, 256 x 53 -- read as the fetch stream moves
bank[2].btb : branch target buffer, halfword bank 2 of 8, 256 x 53 -- read as the fetch stream moves
bank[3].btb : branch target buffer, halfword bank 3 of 8, 256 x 53 -- read as the fetch stream moves
bank[4].btb : branch target buffer, halfword bank 4 of 8, 256 x 53 -- read as the fetch stream moves
bank[5].btb : branch target buffer, halfword bank 5 of 8, 256 x 53 -- read as the fetch stream moves
bank[6].btb : branch target buffer, halfword bank 6 of 8, 256 x 53 -- read as the fetch stream moves
bank[7].btb : branch target buffer, halfword bank 7 of 8, 256 x 53 -- read as the fetch stream moves
bank[0].yc  : YAGS corrector, halfword bank 0 of 8, 256 x 10 -- read as the fetch stream moves
bank[1].yc  : YAGS corrector, halfword bank 1 of 8, 256 x 10 -- read as the fetch stream moves
bank[2].yc  : YAGS corrector, halfword bank 2 of 8, 256 x 10 -- read as the fetch stream moves
bank[3].yc  : YAGS corrector, halfword bank 3 of 8, 256 x 10 -- read as the fetch stream moves
bank[4].yc  : YAGS corrector, halfword bank 4 of 8, 256 x 10 -- read as the fetch stream moves
bank[5].yc  : YAGS corrector, halfword bank 5 of 8, 256 x 10 -- read as the fetch stream moves
bank[6].yc  : YAGS corrector, halfword bank 6 of 8, 256 x 10 -- read as the fetch stream moves
bank[7].yc  : YAGS corrector, halfword bank 7 of 8, 256 x 10 -- read as the fetch stream moves
pq      : the predictor's queue of predictions, one per fetch-ring mark
prd     : load queue destination tag
rdn     : load queue
tlb_tag : iTLB/dTLB
tlb_ppn : iTLB/dTLB
tlb_perm: iTLB/dTLB

# ---- the D$'s physical state: one LUTRAM per (way, colour), 64 rows, read at two rows -------
# (32 at DC_KB=128: 2 ways x 16 colours)
ptw[*].pt_k x32 : D$ physical tags (the line); the probe reads each way's at its set's row, one array each
ptw[*].pv_k x32 : D$ pvalid
ptw[*].pd_k x32 : D$ dirty
mbd_e   : D$ merge buffers, even chunks (as flops they were 4.6k registers and their muxes)
mbd_o   : D$ merge buffers, odd chunks
nru0    : D$ way 0 line recently used, per set
nru1    : D$ way 1 line recently used, per set
