# Arrays that MUST be inferred as RAM. Checked by tools/check-ram-inference.py after
# synthesis; a demotion to flops FAILS THE BUILD and names the array.
#
# Why a manifest and not just an attribute: `(* ram_style *)` asks the tool to try, and
# Vivado warns rather than errors when it cannot -- which is a silent regression on a design
# where nobody reads warnings. The attribute states intent at the declaration, this file
# enforces it. Both are wanted; only this one fails.
#
# Format:  <array-name> : why it must not become flops
# The name is the declared reg array, without the _reg suffix synthesis appends.
# `block[*].array xN` requires N generate instances of an array, every one a RAM; N may be
# `{expr}` in the pipeline width IW (the build's SMOLRV64_IW).
#
# To REMOVE a line you must have decided the array is allowed to be flops -- say so in the
# commit message, with the reason. Do not delete a line to make a build pass.

# ---- the issue queue: the scheduler emits an INDEX, everything else is looked up ---------
# One payload and one source-tag array PER SCHEDULER since two-wide dispatch (item 10b,
# 2026-09-05): a pair dispatches to two different schedulers, so each array keeps one write.
ln[*].plmem x{IW} : issue payload, each lane's scheduler; read at the selected entry, one indexed read
plmem_f : issue payload, the FP scheduler
ln[*].psmem x{IW} : source tags, each lane's scheduler (e_ps itself is read by the wakeup broadcast)
psmem_f : source tags, the FP scheduler
# e_rob is flops: the kill (lanes 5.4e) looks every entry's ROB index up in the dead-entry vector
# each cycle it holds.

# ---- the physical register file: the largest array in the design ------------------------
ish[*].mem x{IW} : PRF integer shards, one per lane; sharded by WRITER so each has ONE write port
fp[*].mem x2 : PRF FP file, a shard per writer (the load landing's, the F stage's), so each has ONE write port

# ---- rename: free lists and maps, initialised by the bitstream and never reset ----------
# A `for` loop over every entry in the reset branch pinned all five into flops (~3,400 bits)
# purely to initialise them. Configuration does that for free. If one of these regresses,
# look for a reintroduced reset loop first.
# One generate block per shard, fl[shard], each with FLNB=next_pow2(IW) banks (one muxed write per
# bank: a cycle's frees land at tail, tail+1, tail+2). Two copies of each map since retire-two /
# dispatch-two (items 10b/10c): one write per bank per cycle is all a LUTRAM has.
fl[*].u.bank[*].mem x{(1 << (IW-1).bit_length())*(IW+2)} : free lists, a shard per lane and SH_FL, SH_FF (the FP loads', the F stage's), next_pow2(IW) banks each (circular FIFO, head read / tail write)
cp[*].rmap x{IW} : committed map, one copy per commit port; read at the sources + c_rd, written at one index (`rnewer` picks)
cp[*].smap x{IW} : speculative map, one copy per rename port; flush clears `lv`, so no wholesale copy is needed (`newer` picks)
cp[*].dmap.smap_d x{IW if IW >= 4 else 0} : its second copy past 15 reads (the destinations' and the commits' reads), at IW=4

# ---- reorder buffer, frontend, predictor, MMU -------------------------------------------
# The ROB holds a row per dispatch group: column k is one array, written by slot k, read by commit
# port k and by the walk (lanes 5.4d/e). The load and store queues' ROB indexes (`rob`) are flops:
# the kill looks every entry's up each cycle it holds.
col[*].mem x{IW} : ROB entries, one column per slot {pold, noret, rd, prd}
rob_ffr : an FP op's exception flags by ROB slot: written when its result lands, read by the retire ports
# The banked queues (smolrv64_bankq): a bank per position mod NB, one write each. The decoupling
# queue's QNB = next_pow2(FW) = 8, the fetch ring's 8, the training queue's 4, each lane's landing
# buffer's 2 (6 at IW=3), and next_pow2(IW) = 4 each for what a dispatch group's row writes: the
# F stage's FIFO, the LQ's and SQ's dispatch records (spl_ld, spl_st), the LQ's PC (pcm), and the SQ's
# PC and seq (two copies of the seq, one per read).
bank[*].mem x{16 + 2*IW + 8*(1 << (IW-1).bit_length())} : the decoupling queue's records, the fetch ring's halfwords, the training queue's payload, the landing buffers' data, the F FIFO, spl_ld, spl_st, the LQ's PC, the SQ's PC and seq
# Multi-writer arrays (smolrv64_mwram), a bank per writer: the arrived addresses' (a bank per lane,
# the LQ's 3 and the SQ's 3) and the load queue's PA (M's fill, the walker's answer: 2).
wb[*].mem x{2*IW+2} : a lane load's or store's VA by LQ/SQ entry (written by its lane, read at M's fill); a load's PA (written by the fill and the walk)
mdw : the memory-dependence wait table: one write a cycle (a replay, a training event, the forget's step), read at dispatch and by training
ras     : return address stack
bank[*].way[*].btb x16 : BTB, 8 halfword banks x 2 skewed ways, 128 x 53 -- read as the fetch stream moves and by training
bank[*].way[*].bc x16  : bimodal counters, 8 halfword banks x 2 skewed ways, 128 x 2 -- read as the stream moves and by training
bank[*].way[*].nu x16  : the recently-trained bit, 8 halfword banks x 2 skewed ways, 128 x 1 -- read and written by training
bank[0].yc  : YAGS corrector, halfword bank 0 of 8, 256 x 10 -- read as the fetch stream moves
bank[1].yc  : YAGS corrector, halfword bank 1 of 8, 256 x 10 -- read as the fetch stream moves
bank[2].yc  : YAGS corrector, halfword bank 2 of 8, 256 x 10 -- read as the fetch stream moves
bank[3].yc  : YAGS corrector, halfword bank 3 of 8, 256 x 10 -- read as the fetch stream moves
bank[4].yc  : YAGS corrector, halfword bank 4 of 8, 256 x 10 -- read as the fetch stream moves
bank[5].yc  : YAGS corrector, halfword bank 5 of 8, 256 x 10 -- read as the fetch stream moves
bank[6].yc  : YAGS corrector, halfword bank 6 of 8, 256 x 10 -- read as the fetch stream moves
bank[7].yc  : YAGS corrector, halfword bank 7 of 8, 256 x 10 -- read as the fetch stream moves
pq0     : the predictor's queue of predictions, even positions (one write a cycle per bank)
pq1     : the predictor's queue of predictions, odd positions
tlb_tag : iTLB/dTLB
tlb_ppn : iTLB/dTLB
tlb_perm: iTLB/dTLB
tlb_g   : iTLB/dTLB {installed, generation}: a flush advances the generation, so no per-entry clear
l2.tlb2 : the second level (mmu L2N) on the first level's miss path, block RAM: the iTLB's 512, the dTLB's 2048

# ---- the I$'s tags: {virtual tag, epoch} per way, block RAM read with the data banks --------
tg0     : I$ way 0 tags, read at the lookup's set (port B) and by the fill (port A)
tg1     : I$ way 1 tags

# ---- the D$'s state: per way, 64 rows (the set), LUTRAM -----------------------------------
way[*].ta x32 : D$ tags, the main lookup's copy, read at its set
way[*].tb x32 : D$ tags, the store lookup's copy, read at the store's set
way[*].va x32 : D$ valid
way[*].da x32 : D$ dirty
way[*].ua x32 : D$ not recently used
mbd_e   : D$ merge buffers, even chunks (as flops they were 4.6k registers and their muxes)
mbd_o   : D$ merge buffers, odd chunks
fva_l : a load entry's full VA, a trap's tval
fva_s : a store entry's full VA, a trap's tval
